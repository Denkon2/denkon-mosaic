A lightweight, flexible classic theme for business websites, agencies, experts and service providers.

== Description ==

Denkon Mosaic is a classic WordPress theme for building service pages, landing pages and company websites with the native block editor.

The theme includes a responsive header and footer, colour-scheme controls, adjustable content width, support for uploaded fonts and a library of editable block patterns. Every pattern is composed of standard WordPress blocks, so text, images, colours, spacing and links can be changed in the editor without a proprietary builder.

Features:

* Responsive classic theme layout with accessible mobile navigation.
* Site logo, primary menu and footer menu support.
* Theme controls for the colour scheme, content width, header, footer and typography.
* English and Russian interface choice in the theme settings.
* Block patterns for hero sections, benefits, stages, FAQs, galleries, partner logos, testimonials, company information and contact forms.
* Compatible with child themes.

The theme does not connect to external services, collect analytics, create user accounts or send site data to third parties. All theme code and bundled placeholder SVG assets are original Denkon assets and are distributed under GPLv2 or later. SVG upload support is intentionally not included; use a dedicated security plugin if that capability is needed.

== Installation ==

1. In WordPress, go to **Appearance > Themes > Add New > Upload Theme**.
2. Upload the `denkon-mosaic.zip` archive and activate the theme.
3. Open **Appearance > Denkon Mosaic** to choose the interface language, colour scheme, content width, header and footer options.
4. Use **Appearance > Menus** to assign menus to the Primary and Footer locations.
5. Insert Denkon Mosaic patterns from the Block Inserter when editing a page or post.

== Frequently Asked Questions ==

= Does Denkon Mosaic require a page builder? =

No. The theme uses the native WordPress block editor and standard Gutenberg blocks.

= Can I change the language of the theme interface? =

Yes. Choose English or Russian in **Appearance > Denkon Mosaic > General settings**. Unknown or missing language values safely use English.

= Will switching the interface language overwrite my existing page content? =

No. The setting changes theme controls and newly inserted patterns. Existing pages, posts and user-created content are not rewritten.

= Can I use a child theme? =

Yes. The theme includes a child-theme creation tool under **Appearance > Themes**. You can also create a standard child theme manually.
